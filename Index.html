Introducción

Este portafolio de evidencias tiene como propósito documentar las actividades, prácticas y proyectos realizados durante el curso de Cómputo en la Nube.


A través de este sitio web se presentan los conocimientos adquiridos relacionados con:

  • Cómputo en la nube (conceptos, tipos de servicios, modelos de implementación). Integración y entrega continua (CI/CD).
  • Docker y contenedores
  • Kubernetes
  • Servicios en la nube
  • Azure y despliegue de aplicaciones
  • Automatización de despliegues de software y APIs.
  • Gestión de seguridad y riesgos en la nube.
  • NGINX, PHP y MySQL
  • Desarrollo web

El portafolio permite mostrar de manera organizada las evidencias y reflexiones personales obtenidas a lo largo del semestre.

Objetivos

Objetivo General

Comprender e implementar tecnologías de cómputo en la nube mediante el uso de herramientas modernas para el despliegue y administración de aplicaciones.


Objetivos Específicos

  • Aprender el uso de Docker y contenedores.
  • Implementar aplicaciones utilizando VM's, Plataforma Azure
  • Desplegar servicios en plataformas cloud como Azure.
  • Desarrollar aplicaciones utilizando PHP, MYSQL y APACHE/NGINX.

Reflexión Final

Durante el curso se adquirieron conocimientos importantes sobre tecnologías modernas utilizadas en el cómputo en la nube y el desarrollo de aplicaciones.


Entre las fortalezas desarrolladas destacan:

  • Capacidad para desplegar aplicaciones.
  • Uso de herramientas cloud.
  • Trabajo con Docker.
  • Desarrollo web básico.

Como áreas de oportunidad se considera continuar practicando automatización, DevOps y administración avanzada de infraestructura cloud.

Conclusión

Este portafolio de evidencias permitió recopilar y organizar las actividades, prácticas y proyectos realizados durante el curso de Cómputo en la Nube. A través de cada evidencia se muestran los conocimientos y habilidades adquiridas en temas como servicios cloud, virtualización, Docker, redes, seguridad informática y despliegue de aplicaciones.


Durante el curso se trabajó con diferentes plataformas y herramientas como AWS, Google Cloud, Microsoft Azure y GitHub, lo que ayudó a comprender cómo funcionan las tecnologías utilizadas actualmente en muchas empresas y organizaciones. También se realizaron prácticas relacionadas con ciberseguridad y administración de infraestructura, fortaleciendo el aprendizaje práctico.


Además de los conocimientos técnicos, este curso ayudó a desarrollar habilidades como la investigación, la resolución de problemas y el aprendizaje autónomo. Cada actividad contribuyó al crecimiento académico y permitió adquirir experiencia en herramientas y tecnologías modernas.


Finalmente, este portafolio representa el esfuerzo y aprendizaje obtenido durante el semestre, sirviendo como evidencia del desarrollo de competencias relacionadas con el cómputo en la nube y las tecnologías de la información.
